# Third-party software preparation notes

The reported experiments use or adapt implementations of LayoutVAE, LayoutTransformer, LayoutGAN++, and LayoutDM. Before release, this document will list the exact upstream repositories, versions or commit identifiers, licenses, local adaptations, and commands used for each baseline.

Complete third-party repositories will not be copied into this project. Only author-created adapters or patches that are necessary to reproduce the reported protocol will be included after license review.
